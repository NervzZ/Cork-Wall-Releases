# Cork Wall — Releases

This repo only hosts published Android builds of [Cork Wall](https://github.com/NervzZ/Corkwall).

**Source code lives in the (private) `NervzZ/Corkwall` repo.** This one is intentionally empty of code — it exists so testers can download installable APKs without needing access to the source.

## Install on your Android phone

Visit **https://nervzz.github.io/Cork-Wall-Releases/** — pick a version, tap to download, tap to install.

First time you do this, Android will ask if you want to allow this source to install apps. Tap "Allow" (it remembers per source).
